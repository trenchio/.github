# Trenchio

### Open-source infrastructure, built for control.

Trenchio is the home of **Trenchserver**, an open-source infrastructure configuration management platform.

We're building a developer-focused platform to automate, manage, and secure infrastructure across Linux and Windows environments.

## Our focus

| Pillar | Focus |
|---|---|
| **Manage** | Declarative configuration management and infrastructure automation |
| **Protect** | Consistent, secure infrastructure operations |
| **Understand** | Infrastructure visibility, compliance and operational insight |

## Trenchserver

Trenchserver is being developed as a lightweight, extensible alternative to traditional configuration management platforms.

Our engineering priorities include:

- Go-native server and endpoint agent architecture
- Declarative YAML-based configuration
- Git-driven infrastructure workflows
- Linux and Windows as first-class platforms
- Secure agent communication and centralized management
- Self-hosted deployment and extensibility

## Development status

Trenchserver is under active development. Capabilities, platform support, reliability and scalability are being implemented and validated incrementally.

We believe in transparent engineering, secure defaults, independent implementation and open collaboration.
